Ce fichier historique est remplacé par GUIDE_INSTALLATION_MAC.md.

La commande « npx nodemon index.js » indiquée auparavant est obsolète : il n'y
a ni fichier index.js ni dépendance nodemon dans ce projet.

Démarrage quotidien :

# Terminal 1 — services techniques
cd ~/Developer/get-poc && docker compose -p get-poc up -d

# Terminal 2 — backend (API)
cd ~/Developer/get-poc/backend && nvm use && npm run start:dev

# Terminal 3 — frontend (Next.js)
cd ~/Developer/get-poc/frontend && nvm use && npm run dev

Ouvrir ensuite http://localhost:3000.

Pour l'installation initiale, les fichiers .env, les buckets MinIO, les
migrations Prisma, l'arrêt, n8n et le dépannage, lire GUIDE_INSTALLATION_MAC.md.
